# Architektur

Hier werden technische Entscheidungen festgehalten, die langfristige Folgen
haben: Schnittstellen, Datenhaltung, Modellintegration, Datenschutz,
Abhängigkeiten und Deployment.

Für jede relevante Entscheidung wird eine Datei nach
`decisions/ADR-<nummer>-<kurztitel>.md` angelegt. Die Vorlage befindet sich in
diesem Ordner. Kleine, reversible Implementierungsdetails gehören ins Logbook.
