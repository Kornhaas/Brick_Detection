# Logbook

Das Logbook ist der verbindliche Arbeitsnachweis für Menschen und AI-Agenten.
Jede abgeschlossene Aufgabe ergänzt die Datei des aktuellen Monats
(`YYYY-MM.md`). Ein Eintrag beantwortet mindestens:

- Was wurde getan und warum?
- Welche Rollen haben geprüft (Architektur, Entwicklung, UX, Test)?
- Welche Prüfungen wurden ausgeführt und mit welchem Ergebnis?
- Welche Risiken, offenen Punkte oder Entscheidungen bleiben?

Keine sensiblen Daten, Tokens oder privaten Nutzerdaten dokumentieren.
